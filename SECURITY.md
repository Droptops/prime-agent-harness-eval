# Security Policy

This repository contains evaluation scripts, prompts, and experiment artifacts. It should not contain credentials or private session material.

## Reporting

Do not publish API keys, private URLs, proprietary datasets, or exploit details in a public issue. Use GitHub private vulnerability reporting when available. If private reporting is unavailable, open a minimal issue without sensitive details and request a private channel.

## Public-repo hygiene

Do not commit API keys, `.env` files, private keys, session URLs, private transcripts, or proprietary source data. Experimental fixtures should be synthetic, public, or explicitly redistributable.
